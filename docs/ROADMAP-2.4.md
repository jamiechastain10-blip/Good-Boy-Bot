# Good Boy 2.4 plan: multiplayer games

All games: join with a button, optional coin bets from the economy module, one message per game that updates in place
(no channel spam), wins counted on `/top` boards.

## First batch
| Game | How it plays |
|---|---|
| **The Heist** | Someone starts a heist; others have 60 seconds to **Join the crew**. Bigger crew, better odds. Animated reveal: the loot is split, or the crew gets busted. |
| **Last One Standing** | Everyone pays in. Each round random events knock players out. The last one left takes the pot. |
| **Quick Draw** | 1v1 for coins. After a random countdown the first to press **Fire!** wins; pressing early loses. |
| **Brain Blast** | Trivia. Everyone answers privately, faster correct answers score more, scoreboard after each round. |
| **Count Up** | Counting channel: count together, one mistake resets it, high score on the board. |

## Later
| Game | How it plays |
|---|---|
| **Throwdown** | Rock-paper-scissors picked in private, best of 3. |
| **Grid Lock** | Tic-tac-toe on a 3x3 grid of buttons. |
| **Drop Zone** | Drop pieces into columns; four in a row wins. |
| **Hot Potato** | Pass it before it blows; whoever holds it when it goes off is out. |
| **Reflex** | Speed rounds, first to press the right button scores. |
| **Imposter** | Secret roles; vote out the imposters before they win. |
| **Fishing Derby** | Weekly fishing tournament for coins and a Top Angler role. |

Not planned: giveaways.
